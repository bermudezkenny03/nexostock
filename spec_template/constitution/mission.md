# Misión

Facilitar la administración de productos, inventario y ventas de pequeños y medianos negocios mediante una plataforma web que reúna estas operaciones, mantenga información organizada y permita consultar oportunamente las existencias y los resultados comerciales. Su valor principal es conectar el registro de ventas con la actualización del inventario, para reducir el trabajo duplicado y mejorar la trazabilidad de las operaciones.

## Qué construimos

Construimos NexoStock, una plataforma web de gestión de inventario y ventas para pequeños y medianos negocios que resuelve las dificultades de registrar existencias en cuadernos o herramientas aisladas. Con este producto se busca solucionar la pérdida de información comercial, las diferencias en las existencias y el tiempo dedicado a revisar registros manuales.

1. Módulo de Productos e Inventario — Permite gestionar un catálogo centralizado, consultar existencias, registrar entradas o salidas conservando el historial y alertar sobre niveles mínimos.
2. Módulo de Ventas — Permite seleccionar productos, calcular totales y registrar ventas, coordinando la actualización automática y descontando las existencias una sola vez.
3. Módulo de Usuarios y Reportes — Controla el inicio de sesión y permisos por rol, y permite consultar indicadores generales y reportes básicos de ventas e inventario.

## Para quién

Usuario principal: Propietarios de pequeños y medianos negocios (como tiendas de barrio y papelerías) que buscan conocer el estado del inventario y consultar información básica de ventas.

Usuarios secundarios: Administradores de inventario que gestionan productos y detectan niveles bajos, y empleados encargados de las ventas que registran los productos vendidos y consultan la disponibilidad.

Otros interesados: El equipo del proyecto académico en el contexto de un diplomado, cuyo objetivo inicial es evaluar la entrega del Producto Mínimo Viable (MVP).

## Principios

Prioridad funcional — Implica completar el flujo de productos, inventario y ventas antes de ampliar el alcance.

Información consistente y trazabilidad — Implica relacionar las ventas con sus movimientos de inventario sin duplicar descuentos, y conservar información suficiente para revisar las operaciones registradas.

Acceso controlado — Implica permitir acciones de acuerdo con los permisos definidos para cada rol.

Uso sencillo — Implica presentar formularios y mensajes que sean comprensibles para los usuarios del negocio.

## Qué NO es

No es un sistema de facturación electrónica ni se integra con sistemas contables.
No está diseñado para la administración de múltiples sucursales.
No incluye aplicaciones móviles nativas.
No tiene integración con pasarelas de pago ni con plataformas externas de comercio electrónico.
No realiza predicciones de demanda mediante el uso de inteligencia artificial.
